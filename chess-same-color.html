Same Color?

Are the two squares the same color? You decide!

How it works:
Convert file to number (a=1 ... h=8) and add the rank.
If the sum is even — the square is on an even group.
If the sum is odd — the square is on an odd group.

Both same group — Yes (same color).
Different groups — No (different color).

Example: c4 = 3+4 = 7 (odd) | e6 = 5+6 = 11 (odd) — Yes!
